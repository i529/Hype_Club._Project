# HypeClub

Este projeto foi feito no angular versão 15.2.11.

# Como instalar

Clone o repositório para a sua máquina e em sequência acesse a pasta pelo cmd, quando acessada, use npm install para que instale as depedências que foram utilizadas no projeto.

## Development server

Rode `ng serve` para rodar no servidor de desenvolvimento. Navegue para `http://localhost:4200/`. O app tem refresh automático no site para cada atualização que fizer no codigo enquanto está rodando.

## Build

Rode `ng build` para rodar a build do projeto.
